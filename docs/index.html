What it does

It indexes the text inside your files (with OCR for scans and photos) into a local database, then matches your own words against it and shows the best files with the page or row and why it picked them.

Install

Windows

Install Python 3.9+ from python.org (tick "Add python.exe to PATH"), then in PowerShell:
py -m pip install git+https://github.com/mohamed-elshamy-ai/wheredidit
py -m pip install .
wheredidit add $HOME\Documents
wheredidit find "your description"
Untested. Should work. Only tested on Linux. OCR needs tesseract installed.

macOS

Python 3.9+ (brew install python or python.org), then in Terminal:
python3 -m pip install git+https://github.com/mohamed-elshamy-ai/wheredidit
pip install .
wheredidit add ~/Documents
wheredidit find "your description"
Untested. Should work. Only tested on Linux. OCR needs tesseract (brew install tesseract).

Linux

Python 3.9+ is usually installed. In a terminal:
python3 -m pip install --user git+https://github.com/mohamed-elshamy-ai/wheredidit
pip install .
wheredidit add ~/Documents
wheredidit find "your description"
Tested. Tested on Linux (Python 3.10) with tesseract.

Android

Not available. It needs to read your folders, and a website cannot.

How it worksإزاي بيشتغل

  1. You add folders. Each file is split into passages (page, slide, sheet row).
  2. Scanned pages and photos go through OCR (the free tesseract program).
  3. Words are normalised: stop words removed, word forms reduced, Arabic spelling unified, synonyms grouped.
  4. Your question gets the same treatment and is matched with SQLite full-text search (bm25), plus a coverage score and a file-name bonus.
  5. Results show the best passage per file and why it matched.
الشرح بالعربي

بتضيف الفولدرات، والأداة بتقرا محتوى كل ملف وبتقسمه لأجزاء، وبتعمل OCR للصور والملفات المصورة لو tesseract متسطب. بعدين بتخزن النص في قاعدة بيانات على جهازك بعد ما توحد الكلمات (شيل الكلمات الزيادة وأصل الكلمة والمرادفات). لما تسأل بجملة عادية بتعمل نفس الحاجة وتدور على أقرب الأجزاء وتوريك الصفحة وسبب الاختيار. مفيش نموذج ذكاء اصطناعي، فلازم وصفك يشارك الملف في كلمات.

Honest limits

  • No meaning-based search: no embeddings. A file that says support vector machine will not match a question that says SVM.
  • The synonym list is small and hand-made.
  • OCR needs tesseract installed (and the Arabic data for Arabic text). Handwriting is poor.
  • Command line only for now. No window app, no audio.
  • watch checks by polling every 30 seconds.
